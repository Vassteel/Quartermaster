## ⚙️ Quartermaster — IN TESTING

Base storage and automation for Valheim, inspired by Hearthkeeper and AutomaticFermenters.

• **Deposit Chests** sort supplies into chests that remember their item types—even when empty.
• Automatically supplies fires, torches, machines, cooking racks and animals from base storage.
• Craft, build and upgrade using stored supplies.
• Finished products drop normally, with **60 seconds** to collect them before automatic storage.
• **100m default range**, adjustable to 200m for loaded base objects, plus production caps to prevent endless processing.
• Glowing gears and runes mark Deposit Chests; receiving chests briefly glow.

**v0.1.2: early local playtesting.** Multiplayer still needs testing. Feedback and bug reports welcome!
